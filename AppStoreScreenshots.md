# ReadForge App Store Screenshots Guide

## Required Screenshots

### iPhone Screenshots (6.7" Display)
1. **Library View** - Show document list with import button
2. **Document Detail** - Show PDF content with play controls
3. **Player View** - Show audio playback interface
4. **Settings View** - Show voice and playback settings
5. **Import Flow** - Show file picker and import process

### iPad Screenshots (12.9" Display)
1. **Library Landscape** - Show document library in landscape
2. **Split View** - Show app alongside another app
3. **Document Detail** - Show PDF on larger screen
4. **Player View** - Show audio controls on iPad
5. **Settings View** - Show settings on iPad

### Apple Watch Screenshots (if applicable)
- Not required for v1.0

## Screenshot Specifications

### iPhone Requirements
- **Size**: 1290 x 2796 pixels (6.7" display)
- **Format**: PNG or JPEG
- **Color**: sRGB
- **No device frames**
- **No status bar overlays**

### iPad Requirements
- **Size**: 2048 x 2732 pixels (12.9" display)
- **Format**: PNG or JPEG
- **Color**: sRGB
- **No device frames**
- **No status bar overlays**

### Content Guidelines

#### Library View Screenshots
- Show clean document list
- Include import button prominently
- Show empty state if no documents
- Demonstrate search/filter if available
- Show document metadata (title, pages, duration)

#### Player View Screenshots
- Show audio playback controls
- Display progress bar
- Show playback speed controls
- Include voice selection
- Show background audio indicator

#### Settings Screenshots
- Show voice settings
- Display playback speed options
- Show privacy settings
- Include accessibility options
- Demonstrate AI toggle

#### Import Flow Screenshots
- Show file picker interface
- Display import progress
- Show supported file types
- Include error states
- Show success confirmation

## App Preview Video (Optional but Recommended)

### Video Specifications
- **Duration**: 15-30 seconds
- **Format**: M4V, MP4, or MOV
- **Resolution**: 2160 x 3840 (iPhone 6.7")
- **Frame Rate**: 30 FPS minimum
- **Bitrate**: 10 Mbps or higher
- **No device frames**

### Video Content Flow
1. **Opening** - App launch animation (0-2s)
2. **Library** - Show document library (2-8s)
3. **Import** - Document import process (8-12s)
4. **Playback** - Audio playback demonstration (12-18s)
5. **Features** - Highlight key features (18-25s)
6. **Closing** - App logo and tagline (25-30s)

## App Store Icon Requirements

### Icon Sizes
- **1024 x 1024 pixels** (App Store)
- **60 x 60 pixels** (@2x = 120x120) (iPhone)
- **60 x 60 pixels** (@3x = 180x180) (iPhone)
- **40 x 40 pixels** (@2x = 80x80) (iPad)
- **40 x 40 pixels** (@3x = 120x120) (iPad)
- **29 x 29 pixels** (@2x = 58x58) (Settings)
- **29 x 29 pixels** (@3x = 87x87) (Settings)
- **20 x 20 pixels** (@2x = 40x40) (Notifications)
- **20 x 20 pixels** (@3x = 60x60) (Notifications)

### Icon Guidelines
- **No transparency**
- **No rounded corners** (system adds them)
- **90-degree corners** (system rounds them)
- **Flat design** (no gloss or effects)
- **High contrast** for visibility
- **Unique and recognizable**

## Localization Requirements

### Metadata Localization
- **App Name**: Translate for each supported language
- **Subtitle**: Localize "Turn PDFs into Private Audiobooks"
- **Description**: Full translation for each language
- **Keywords**: Localize keywords for each market
- **What's New**: Translate release notes

### Screenshot Localization
- **UI Elements**: Show localized interface
- **Text Content**: Use localized text where visible
- **Cultural Adaptation**: Consider cultural differences
- **Date/Time**: Use local formats
- **Text Direction**: Support RTL languages if applicable

## Quality Assurance

### Technical Requirements
- **No compression artifacts**
- **Proper aspect ratios**
- **Consistent styling**
- **No copyrighted material**
- **No device frames or bezels**

## Submission Tips

### Before Upload
1. **Test on actual devices** - Ensure screenshots match real experience
2. **Check App Store Connect** - Verify current requirements
3. **Review competitors** - Ensure screenshots stand out
4. **Get feedback** - Test with target users
5. **Double-check specs** - Verify all requirements met

### Upload Process
1. **Create app version** in App Store Connect
2. **Upload screenshots** to appropriate device categories
3. **Add app preview** if available
4. **Set primary screenshot** for each device
5. **Review and submit** for review

### Common Issues to Avoid
- **Wrong dimensions** - Double-check all sizes
- **Poor quality** - Use high-resolution screenshots
- **Outdated UI** - Use current app version
- **Missing devices** - Include all required device types
- **Localization errors** - Verify all translations
- **Inconsistent branding** - Maintain visual consistency
